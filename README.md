# Vite Publishing Template

빌드 결과가 아래 구조로 생성되는 퍼블리싱 템플릿입니다.

```text
dist/
├─ index.html
├─ guide/
│  └─ coding-list.html
├─ pages/
│  ├─ login.html
│  ├─ notice-list.html
│  └─ notice-detail.html
├─ data/
│  └─ coding-list.json
└─ assets/
   ├─ css/
   ├─ js/
   └─ images/
```

## 설치

```bash
npm install
```

## 개발

```bash
npm run dev
```

## 빌드

```bash
npm run build
```

코딩리스트는 `/guide/coding-list.html`에서 확인합니다.
